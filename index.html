¿Cómo preparo un archivo JSON?

Cada asignatura tiene su propio archivo dentro de data/. Debe contener un nombre de asignatura y una lista de temas; cada tema contiene preguntas y respuestas. Añade el archivo a manifest.json para mostrarlo en la biblioteca. 

{
  "asignatura": "Matemáticas",
  "temas": [
    {
      "nombre": "Álgebra",
      "tarjetas": [
        {
          "pregunta": "¿Qué es una ecuación?",
          "respuesta": "Una igualdad con una o más incógnitas."
        }
      ]
    }
  ]
}
