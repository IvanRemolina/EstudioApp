¿Cómo preparo un archivo JSON?

Cada asignatura tiene su propio archivo dentro de data/. Puede usar tarjetas con pregunta y respuesta, o preguntas tipo test con opciones y la clave correcta. Añade el archivo a manifest.json para mostrarlo en la biblioteca. 

{
  "asignatura": "Contabilidad Financiera",
  "tema": "Tema 1",
  "preguntas": [
    {
      "pregunta": "¿Qué representa el pasivo?",
      "opciones": {
        "A": "Deudas y obligaciones",
        "B": "Activos y recursos"
      },
      "respuesta_correcta": "A"
    }
  ]
}
